# Gunina Holidays — Destination Photo Build

This ZIP preserves the existing site and adds a centralized photo-first system for every destination.

IMPORTANT: This build does not falsely bundle stock photos that are not actually present.
The existing destination SVGs remain the guaranteed fallback. The new manifest is the exact place
to put one properly licensed real photograph URL or local image path per destination.

For a commercial website, Pexels states that its photos can be used commercially, but its terms also
restrict bulk/systematic copying. Use individually selected, properly licensed images rather than scraping
the service at scale.

Once actual image files are supplied, place them in:
assets/images/destinations/

and set each manifest value to its local filename/path.
